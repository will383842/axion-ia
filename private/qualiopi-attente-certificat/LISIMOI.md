# Visuels Qualiopi en attente du certificat

Ces cinq images affirment la certification (« certifié », « qualité certifiée »).
Elles sont sorties de `public/` tant que le certificat n'est pas obtenu : rien ici
n'est servi par le site. Pour les remettre en ligne après le certificat, les
replacer (même arborescence) dans `public/`, et
remettre leurs références (`src/lib/seo/page-images.ts`, page
`certification-qualiopi`).
