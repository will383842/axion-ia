## 🔍 PÉRIMÈTRE D'AUDIT — 15 CHAPITRES × 10 CRITÈRES = 150 POINTS

### Chapitre 1 — Fondations techniques

1.1 HTTPS/SSL : certificat valide, HSTS header présent (max-age ≥ 31536000), preload list.
1.2 Status codes : 200 sur indexable, 301 redirects propres (pas 302), 404 custom + non-indexée.
1.3 Redirections : pas de chaînes (max 1 saut), HTTP→HTTPS, www→apex (ou inverse), trailing-slash policy stricte.
1.4 robots.txt : règles standard + AI bots (cf. chapitre 13).
1.5 sitemap.xml : multi-sitemaps via index, max 50K URLs/sitemap, lastmod précis, priority/changefreq.
1.6 Indexation : Search Console + Bing Webmaster setup vérifiés, IndexNow API configurée.
1.7 DNS : TTL raisonnable, CAA records, MX dédié si email maison (mémoire `axionia_project` confirme email maison).
1.8 Domaine : âge, autorité, pas de spam history.
1.9 Server : TTFB < 800ms P75, HTTP/2 minimum (HTTP/3 idéal), Brotli compression.
1.10 Security headers : CSP strict, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy (Mozilla Observatory cible A+).

### Chapitre 2 — HTML sémantique & structure

2.1 DOCTYPE HTML5 (`<!DOCTYPE html>`) sur toutes pages.
2.2 `<html lang="fr">` ou `lang="en"` selon locale, `dir="ltr"` explicite.
2.3 `<meta name="viewport" content="width=device-width,initial-scale=1">` strict (pas de `user-scalable=no`).
2.4 Landmarks ARIA : `<header>`, `<nav>` (avec `aria-label`), `<main>` (un seul, `id="main"` pour skip link), `<aside>`, `<section>` avec `aria-labelledby`, `<article>`, `<footer>`.
2.5 H1 : **un seul H1 par page**, descriptif, contient mot-clé principal.
2.6 H2-H3-H4 hiérarchie : pas de saut de niveau (H1→H3 sans H2 = erreur), max profondeur H4 (H5/H6 anti-pattern moderne).
2.7 `<article>` pour blog/case-studies/help, `<section>` pour groupements thématiques.
2.8 Skip links : `<a href="#main">` first focusable, visible au focus.
2.9 Microdata vs JSON-LD : **JSON-LD obligatoire** (Google preferred 2026), microdata HTML deprecated.
2.10 `<time datetime="2026-05-07">` pour toutes dates (machine-readable).

### Chapitre 3 — Métadonnées HTML head (par page)

3.1 `<title>` : 50-60 caractères, kw principal en début, brand AxionIA en fin (`| AxionIA` ou `· AxionIA`).
3.2 `<meta name="description">` : 140-160 caractères, naturel, CTA implicite, pas de bourrage kw.
3.3 OpenGraph complet : `og:type`, `og:url`, `og:title`, `og:description`, `og:image` (1200x630 minimum), `og:locale` (`fr_FR` / `en_US`), `og:site_name`.
3.4 Twitter Card : `twitter:card="summary_large_image"`, `twitter:site`, `twitter:creator`, `twitter:title`, `twitter:description`, `twitter:image`.
3.5 `theme-color` : terracotta `#c24a1b` ou mocha `#2a2520` selon scheme, `media="(prefers-color-scheme: dark)"` si dark mode.
3.6 `manifest.json` : PWA-ready (icons toutes tailles, name, short_name, description, start_url, display, theme_color, background_color, scope, lang).
3.7 Favicons exhaustifs : `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` (180x180), `icon-192.png`, `icon-512.png`, `icon-maskable.png`.
3.8 `<link rel="canonical">` strict (cf. chapitre 4).
3.9 `<link rel="alternate" hreflang>` matrix complète (cf. chapitre 4).
3.10 OG image dynamique par page via `ImageResponse` Next.js 16 (`opengraph-image.tsx` template SSR React→PNG).

### Chapitre 4 — Canonical & internationalization

4.1 Canonical absolu (URL complète https://axion-ia.com/...), strict, pas de mismatch trailing-slash.
4.2 Self-canonical sur toutes pages indexables (même celles sans variant).
4.3 Pages paginées : canonical sur self, pas sur page 1 (Google 2024+ guidance).
4.4 Pages filtrées (`?categorie=rag`) : canonical vers version sans filtres OU `noindex` selon stratégie.
4.5 hreflang matrix : `fr` ↔ `en` ↔ `x-default` (= `fr` pour AxionIA).
4.6 hreflang réciprocité : si A pointe B, B pointe A (sinon Google ignore).
4.7 hreflang format : `<link rel="alternate" hreflang="fr" href="https://axion-ia.com/fr/audit">` (URL absolue obligatoire).
4.8 hreflang en sitemap (alternative à `<head>`, redondant idéal pour robustesse).
4.9 Locale-specific routes : `routing.pathnames` aligné (ex: `/blog/categorie/:slug` FR ↔ `/blog/category/:slug` EN, déjà OK).
4.10 No-index pages : `/preferences-cookies`, `/desabonnement`, `/mes-donnees`, `/confirmation`, `/recherche` (déjà EXCLUDED_FROM_INDEX dans sitemap, vérifier `metadata.robots = { index: false }` côté page).

### Chapitre 7 — On-page content SEO 2026

### Chapitre 12 — Core Web Vitals & vitesse 2026

12.9 Cache : `Cache-Control` immutable assets, ISR strategy pour pages dynamiques, CDN edge cache (Vercel default).
