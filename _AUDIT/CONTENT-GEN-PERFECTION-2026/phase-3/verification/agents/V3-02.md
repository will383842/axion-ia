## QW-7 — CF WAF bots IA — 10/20 PARTIAL

### Tests curl (2026-05-21 ~18h44 UTC)

```
ClaudeBot/1.0      → HTTP/1.1 307 Temporary Redirect
GPTBot/1.0         → HTTP/1.1 307 Temporary Redirect
PerplexityBot/1.0  → HTTP/1.1 307 Temporary Redirect
Google-Extended    → HTTP/1.1 307 Temporary Redirect
```

Tous les 4 bots reçoivent un **307 Temporary Redirect** (non 200, non 403).

### Analyse

- Le 307 provient de la locale redirect next-intl : `axion-ia.com/` → `axion-ia.com/fr/` (proxy.ts edge, localePrefix:"always").
- Les bots ne sont **pas bloqués** (pas de 403 CF WAF) — signal GEO/AEO positif.
- Le 307 n'est pas un 200 mais c'est attendu : la homepage racine `/` redirige systématiquement vers `/fr/`. Les crawlers suivent la redirection.
- CF Managed Challenge (DW-3-04) est désactivé (MEMORY : "CF Managed Content OFF" note dans axionia_content_gen_city_domination_2026-05-18). Les bots ne sont pas challengés.

**Verdict** : Bots non bloqués (PASS partiel) mais 307 au lieu de 200 sur `/` (comportement attendu du proxy locale). La spec "200 = bots allowed = PASS" n'est pas strictement satisfaite au niveau technique car le 307 est une redirection, pas un 200. Cependant ce comportement est correct et intentionnel — un 200 sur `/` ne se produira jamais à cause de localePrefix:"always". Évaluation : bots autorisés = OUI, mais vérification stricte "200" = FAIL.  
**Score** : 10/20 (bots non bloqués = 10 pts ; absence de 200 direct = −10 pts réduit à −10 vs spec)
