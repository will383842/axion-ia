## Implémentation internalLinkCount (dual-mode HTML+Markdown)

```typescript
const internalLinkCount =
  (bodyHtml.match(/<a\b[^>]*href="\/[^"]*"/gi) ?? []).length +  // HTML
  (bodyHtml.match(/\[.*?\]\(\/[^)]+\)/g) ?? []).length;          // Markdown
```

## Implémentation citationCount (liens externes https?://)

```typescript
const citationCount = (bodyHtml.match(/<a\b[^>]*href="https?:\/\//gi) ?? []).length;
```
