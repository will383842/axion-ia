# Vérification de l'interface — module formateurs indépendants (2026-10-17)

Question de Will : « l'interface est-elle COMPLÈTE, surtout la console ? »
Méthode : lecture du code (aucun fichier de `src/` modifié), grep des appelants, tests existants. Pas de build de production, pas de Playwright (le banc exige une base réelle).

## Verdict

**Presque complète, avec 3 trous qui comptent avant d'allumer.** Les 47 clés sont pilotables depuis l'écran Interrupteurs, aucune action serveur n'est orpheline, et presque toutes les pages ont garde de droits + « pas encore ouvert » qui nomme la clé. Les manques sont de la **navigation** (3 pages sans lien) et des **404 muets**.

## Banc

- `vitest run` ciblé (`src/components/admin/qualiopi`, `src/server/qualiopi/formateurs-independants`, `src/server/actions/qualiopi`) : **298 fichiers, 3 420 tests, tout vert**.
- Premier passage : 60 fichiers rouges, uniquement parce que le client Prisma n'était pas généré dans le conteneur (`prisma/generated/client` absent). Après `prisma generate` : vert. Ce n'est pas un défaut du dépôt.
- Playwright : non lancé (79 fichiers sous `tests/e2e/formateurs`, tous dépendent d'une base).
- Limite : les tests ne couvrent pas le rendu des états de pages serveur ; ce rapport vient de la lecture du code.
