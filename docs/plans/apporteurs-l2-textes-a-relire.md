# L2 — Textes que le dirigeant doit relire

Lot L2 du plan `apporteurs-sept-points-salariat-2026-11-25.md` : « Retirer du réseau » est
refusé pour un apporteur sous contrat ; le geste devient « Classer le dossier (non signé) ».
Libellés neufs (aucun texte du contrat n'est touché) :

| Où                             | Texte                                                                                                                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Résumé du formulaire (fiche)   | « Classer le dossier (non signé) »                                                                                                                                                               |
| Champ                          | « Motif du classement (obligatoire) » (3 à 500 caractères)                                                                                                                                       |
| Aide sous le champ             | « Sans nom, adresse, téléphone ni coordonnées bancaires » (les e-mails, téléphones et IBAN saisis sont masqués dans la colonne ; le journal ne reçoit pas le texte)                              |
| Bouton                         | « Classer le dossier »                                                                                                                                                                           |
| Dossier déjà classé            | « Dossier classé le … Le lien du dossier ne fonctionne plus. Rien n'a été effacé. »                                                                                                              |
| Dossier sous contrat (fiche)   | « Contrat en cours : un dossier sous contrat ne peut pas être classé. Pour y mettre fin, utilisez « Résilier le contrat » (préavis de 30 jours, art. 11.1). Les commissions dues restent dues. » |
| Refus `signe`                  | « Contrat en cours : le classement n'est pas possible. Pour mettre fin au contrat, utilisez « Résilier le contrat » (article 11). »                                                              |
| Refus `a_verifier`             | « Contrat signé par l'apporteur, en attente de votre contresignature : refusez le dossier ou contresignez-le. »                                                                                  |
| Motif absent ou hors bornes    | « Indiquez le motif du classement (3 à 500 caractères). »                                                                                                                                        |
| Succès                         | « Dossier classé et lien du dossier désactivé. Rien n'a été effacé. »                                                                                                                            |
| Déjà classé                    | « Ce dossier est déjà classé. »                                                                                                                                                                  |
| Suppression définitive refusée | « … Utilisez « Classer le dossier » » ou, pour un dossier signé, « … utilisez « Résilier le contrat » »                                                                                          |

Le parcours « refuser un dossier à vérifier » existe (`verification.ts`, statut `refuse`) : le texte du refus `a_verifier` est exact.
Décision D2 (apporteurs déjà retirés sous contrat) : non traitée par ce lot.
