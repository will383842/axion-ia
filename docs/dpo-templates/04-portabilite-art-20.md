# Template DPO 04 — Réponse demande de portabilité (RGPD art. 20)

**Usage** : utilisateur demande à recevoir ses données dans un format structuré (transmission à un autre responsable).
**Délai légal** : 30 jours.
**Action interne** : utilisateur s'auto-sert via `/api/gdpr-export` (Sprint 24/D2). Pas d'action admin requise sauf édge cases.

## Corps — FR

Bonjour [Prénom],

Nous accusons réception de votre demande de portabilité, conformément à l'article 20 du RGPD.

Vous pouvez télécharger immédiatement vos données dans un format structuré, lisible par machine (JSON), via notre service self-service :

👉 https://axion-ia.com/fr/mes-donnees

Le fichier JSON inclut toutes les données que vous nous avez fournies dans le cadre de l'exécution d'un contrat ou de votre consentement (art. 20.1) :

- soumissions de formulaires (audit, contact, intervention, implémentation)
- statut newsletter
- réservations confirmées

Vous pouvez transmettre ce fichier directement à tout autre responsable de traitement de votre choix.

**Limite légale** : les données dérivées (ex : statistiques anonymisées Plausible, logs techniques) ne sont pas concernées par le droit à la portabilité car elles ne vous sont pas directement attribuables.

Si vous souhaitez que nous transmettions directement ces données à un autre responsable de traitement, indiquez-nous ses coordonnées et son adresse de réception.

Cordialement,
DPO Axion-IA SAS
contact@axion-ia.com
